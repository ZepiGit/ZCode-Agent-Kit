USAGE
  zcode-kit <command> [options]

COMMON TASKS
  first run, answers y/n per assistant
    $ zcode-kit setup
  unattended, no questions
    $ zcode-kit setup --harness omp,codex
  base URLs, key and models for a manual client
    $ zcode-kit proxy status
  repair kit-owned config and restart a dead proxy
    $ zcode-kit doctor --fix

COMMANDS
  get started
    setup                           Detect assistants, ask once per assistant, configure the local provider
    integrate <harness>             Configure one assistant explicitly (--dry-run shows the changes)
    run <harness> -- <args>         Start an assistant wired to the local proxy
  check and fix
    doctor                          Check runtime, proxy, account and integrations (--fix repairs, --json)
    status                          Proxy health, memory, quota and connection details (--json)
    models                          Model ids served by the proxy (--show-key prints the local key)
  proxy service
    proxy start|stop|restart        Manage the local proxy (never touches a service it did not start)
    proxy status|logs [n]           Show state or the last n log lines
  accounts
    auth status|login|logout        ZCode login used by the proxy
    accounts [health|quota|doctor]  Account Rotator pool (enable|disable|pause|resume|remove)
  maintenance
    update [--version vX.Y.Z]       Update the kit, keep your configuration
    rollback [tx-id]                Undo the last (or a given) change set
    uninstall                       Remove kit-owned integrations; logins are kept
