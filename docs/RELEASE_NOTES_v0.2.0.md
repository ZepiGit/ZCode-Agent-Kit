# zcode-agent-kit v0.2.0

Initial public release of ZCode Agent Kit.

- A command-line setup tool for connecting supported coding assistants to a
  user's ZCode Desktop account.
- A local provider proxy and optional MCP bridge.
- Installers for Windows, macOS, and Linux.

See the [main README](../README.md) for current requirements and setup
instructions. The archived [v0.2.0 release](https://github.com/ZepiGit/ZCode-Agent-Kit/releases/tag/v0.2.0)
contains the original release assets.
